# Beta feedback log

Raw feedback from concierge beta testers (massage salons, osteopath practices, similar). Collected via **email or chat apps**, then summarized here for product decisions.

See also: [`PROJECT_STATE.md`](./PROJECT_STATE.md) (beta strategy, backlog), [`BETA_GUIDE.md`](./BETA_GUIDE.md) (tester onboarding).

---

## How to use

1. Tester sends feedback by email or chat.
2. Add an entry below (copy the template).
3. Link actionable items to `PROJECT_STATE.md` backlog when prioritizing.

### Entry template

```markdown
### YYYY-MM-DD — [Business type / role, optional name]

**Channel:** email | WhatsApp | Telegram | other

**Summary:** one-line gist

**Verbatim / notes:**

- ...

**Action items:**

- [ ] ...
```
